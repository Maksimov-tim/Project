# Автоматизированная система приёма и регистрации кернов (MVP)

Программное обеспечение для автоматизации переноса данных с маркировочных бирок керна в электронные таблицы с использованием оптического распознавания символов (OCR). Проект разработан для нужд Окружного кернохранилища ХМАО-Югры (АУ «НАЦ РН им. В.И. Шпильмана»).

## 📌 О проекте

Текущий ручной процесс приема и регистрации ящиков с керном требует больших временных затрат. Данный MVP (минимально жизнеспособный продукт) автоматизирует извлечение метаданных (месторождение, скважина, интервал глубин, номер ящика) с фотографий бирок и формирует итоговый отчет в формате Excel.

**Основные возможности:**
- Предобработка изображений (нормализация, повышение контрастности) с помощью `Pillow` и `NumPy`.
- Распознавание текста с помощью нейросети `EasyOCR`.
- Интеллектуальная автокоррекция текста на основе алгоритма Левенштейна и словаря месторождений (`PySpellChecker`).
- Валидация данных с помощью регулярных выражений.
- Автоматическое формирование и экспорт ведомости в `.xlsx` (`OpenPyXL`).

## 🚀 Установка и запуск

1. Клонируйте репозиторий на свой компьютер:

```bash
git clone https://github.com/ТВОЙ_НИКНЕЙМ/MVP_project.git
cd MVP_project
```

2. Создайте и активируйте виртуальное окружение (рекомендуется):

```bash
python -m venv venv
```

Для Windows:

```bash
venv\Scripts\activate
```

Для Mac/Linux:

```bash
source venv/bin/activate
```

3. Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

*Примечание: Если при установке `torch` возникают ошибки, установите CPU-версию вручную:*

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
```

4. Поместите тестовые фотографии бирок (в формате `.jpg`, `.png` и т.д.) в папку `Code/data/images/`.

5. Запустите скрипт из корневой папки проекта:

```bash
python Code/src/MVP.py
```

## 📊 Результаты работы

Скрипт обрабатывает все изображения из папки `Code/data/images/` и создает файл `core_labels.xlsx` в папке `Code/src/` (рядом со скриптом). В консоль выводится подробная статистика по распознанным полям.

- Точность распознавания ключевых полей: **95%**.
